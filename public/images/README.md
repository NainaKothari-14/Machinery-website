# Put your images here

Paths in `src/content/` use `/images/...` which maps to this folder.

## Folders

| Folder | Used for |
|--------|----------|
| `hero/` | Home page background |
| `about/` | About section photos |
| `gallery/` | Gallery page + video thumbnails |
| `machines/` | Machine catalog photos |
| `brand/` | Company logo (navbar, footer, favicon) |

Example: `public/images/machines/sealer-auto.jpg` → use `"/images/machines/sealer-auto.jpg"` in content files.

Supported: `.jpg`, `.jpeg`, `.png`, `.webp`
